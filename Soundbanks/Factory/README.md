# Factory soundbank — WaveBombz WASP

Eight original starter presets inspired by the bold, raw, analog-style character associated with classic Wasp-era synthesizers. These are new presets, not copied original factory data.

- Acid Bite — resonant acid lead
- Neon Pulse — bright animated synth
- Brass Stab — punchy brass-like hit
- Deep Sub — rounded mono bass
- Wasp Lead — detuned lead
- Tech Pluck — short percussive pluck
- Dark Drone — slow evolving pad/drone
- Retro Bass — gritty vintage bass

## Load the bank
In the plugin, choose **OPEN BANK** and select this Factory folder. Select a preset from the preset menu. User presets can be saved as .wasp files and loaded individually or stored together in another folder to create a custom soundbank.
